Einrichtung

Hier findet ihr einige Tipps, um für das Semester in NumCS für alle Herausforderungen gewappnet zu sein.

Wichtige Packages

Folgende Python-Packages werdet Ihr in den folgenden Wochen regelmässig gebrauchen:

  • numpy
  • scipy
  • matplotlib
  • ipython / jupyter
  • sympy

Jede dieser packages lässt sich installieren mit:

pip install <name des pakets>

Jupyter & iPython

Ihr könnt Jupyter Notebook auf der Try Jupyter-Seite kostenlos ausprobieren. Ich empfehle euch allerdings, Notebook direkt auf Eurem System zu installieren. Dazu installiert Ihr zuerst Jupyter mit pip, dem Python-Paketmanager:

pip install jupyter

Nun könnt Ihr Notebook mit folgendem Befehl ausführen:

jupyter notebook

Das GUI findet Ihr danach auf http://localhost:8888/tree in eurem browser.

(Quelle: https://jupyter.org/install)

Nachdem ihr Jupyter installiert habt, könnt ihr ebenfalls iPython nutzen mit:

ipython
