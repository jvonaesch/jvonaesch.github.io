NumPy – Rechnen mit Arrays¶

Python-Listen sind sehr langsam für numerische Berechnungen. Wir verwenden die ndarray von NumPy. Diese haben einen festen Typ (wie double[] in Java), auf dem Operationen elementweise und ohne Schleife laufen («vektorisiert»).

Java

double[] a = {1, 2, 3};
double[] b = {4, 5, 6};
double[] c = new double[3];
for (int i = 0; i < 3; i++) {
    c[i] = a[i] * b[i] + 1;
}

Python mit NumPy

a = np.array([1, 2, 3])
b = np.array([4, 5, 6])
c = a * b + 1          # elementweise, keine Schleife

Meshgrid-Beispiel

In [34]:
import numpy as np
import matplotlib.pyplot as plt


def huegel(x, y):
    """Ein Hügel: Höhe 1 im Ursprung, fällt nach aussen ab."""
    return np.exp(-(x**2 + y**2))


# 1) Achsen: 5 Punkte von -2 bis 2
x = np.linspace(-2, 2, 5) # [-2. -1.  0.  1.  2.]
y = np.linspace(-2, 2, 5)

# 2) Gitter: alle 5 x 5 = 25 Kombinationen von x und y
X, Y = np.meshgrid(x, y)

# 3) Funktion auf allen 25 Punkten gleichzeitig auswerten
Z = huegel(X, Y)

print("X =\n", X)
print("Y =\n", Y)
print("Z =\n", np.round(Z, 2))       # Zeile i, Spalte j: Höhe am Punkt (x[j], y[i])

plt.figure()
plt.contourf(X, Y, Z)
plt.colorbar()
plt.title("Hügel von oben")

plt.show()
